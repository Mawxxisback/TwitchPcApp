# 🎮 Twitch PC (Electron)

A **desktop Twitch application for Windows**, built with **Electron**.  
Use Twitch in a dedicated window without opening a browser, with a simple and extensible foundation.

> ⚠️ Unofficial project — not affiliated with Twitch.

---

## ✨ Features

- 🖥️ Native Twitch app for PC
- 🚀 Built with Electron
- 🎨 Custom Twitch icon
- 🔒 Electron security (`contextIsolation`)
- 📦 Build a Windows `.exe`
